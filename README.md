# Img2Img Prompt Library

当前正式版本 v4.3（2026-11-06）：https://prompt-library-pengjia3915.netlify.app/

首页以直接复制为主，支持常用、最近复制与收藏；自由组合保留在次要工具入口。754 条主库记录中，519 条完整内容可直接复制，235 条组件仍可用于组合。动作参考有 251 组、1254 个视角，支持参考图换姿势与纯文字指令；服装参考有 1407 套、8 类、独立中文描述，支持纯文字和双图换装。

所有原始 Prompt、ID、分类、标签及个人存储和同步协议保留。图片核对不等于生图实测。服装图从来源站点按需加载，不批量保存高清原图。场景试用不属于正式版本，备份与发布包均不收录其页面、数据或图片，也不收录服装审阅联系图和缩略图。

## 本地运行

运行 `npm ci` 安装函数依赖，运行 `node scripts/preview-server.mjs` 后打开 http://127.0.0.1:4312/。

验证使用 `npm test` 与 `npm run build`。正式发布目录为 `dist/client`，同步函数源码为 `netlify/functions/sync.mjs`。构建采用明确的文件清单，并拒绝场景试用及复核材料进入客户端目录。

## 发布与回退

本仓库是指定 Netlify 版本的源码与构建备份，并非 Prompt Garden。不要在没有授权时执行发布脚本或推送。v4.3 发布记录、逐文件清单和线上核对结果位于 reports/release-v4.3-*.json。

通过 Netlify 的历史 Deploy 可回退到已验证版本。此次更新前的正式部署为 `6ae5d4379ea0c88a65d8472f`（v4.2），当前部署为 `6aed51831851986da2b1cc2f`（v4.3）。
