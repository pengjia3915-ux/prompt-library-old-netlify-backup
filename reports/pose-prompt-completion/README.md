## 图片核对方法与边界

本轮分片核对57张联系图，覆盖新增的全部1129张现有视角缩略图；对17张细节不明或标题与动作不符的原图进一步放大核对。各分片review.md记有逐张联系图与放大原图记录。主任务另复核双人全部90视角和单人样例。没有把这些检查说成逐张1254原图的详细审查，也没有进行图像生成测试。

每组保存共同姿态，每个真实view id保存对应可见关系。视角图不一致时按当前图描述，未知左右使用一侧/另一侧，不臆造遮挡手脚。上半身只描述可见部分；双人指令分别保留两人身份，不再套用单人模板。

原始标题、catalog记录与图片均未修改；标题与图片有差异时，文字遵循图片而不是猜测标题。动作词为本轮整理正文，不冒充上游原作者文本。
